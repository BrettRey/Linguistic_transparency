\section*{Data availability}

The corpus material behind §\ref{sec:2} and Appendix~\ref{sec:A-3} is the COCA and COHA pilot described there: the full query list, raw returns, per-cell coding decisions, and the pre-registered protocol and results for the \mention{piles} candidate-member test. These files travel with the paper as supplementary material and are versioned in the project repository at \url{https://github.com/BrettRey/Linguistic_transparency}. A citable archive with a persistent identifier will be deposited on acceptance; the repository commit corresponding to this manuscript is recorded in the supplementary README so that every count reported here can be traced to the query that produced it.
